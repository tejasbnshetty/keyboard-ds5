Set up PS5 Remote

  1. Find PS5
  2. Sign in
  3. Pair
  4. Rest mode
  5. Done

1. Find your PS5

Turn the PS5 fully on (not rest mode) and make sure this PC is on the same network. Then search.

Enter the IP address instead

On the PS5: Settings → Network → Connection Status → View Connection Status → "IPv4 Address".

2. Sign in to PlayStation Network

This reads your PSN account ID, which pairing needs. Only the account ID is kept; your password never touches this app and Sony's sign-in token is discarded.

Sign-in isn't configured in this copy of the app (no psn_client.json). See the README section "PSN sign-in values".

After signing in, the browser lands on a page starting with https://remoteplay.dl.playstation.net/remoteplay/redirect?code=. The page may look blank or show an error — that's normal. Copy the whole address from the address bar (Ctrl+L, Ctrl+C), paste it here, quickly (it expires in a minute or two).

3. Pair with the PS5

  1. On the PS5 (fully on): Settings → System → Remote Play, and turn on Enable Remote Play.
  2. Choose Link Device. An 8-digit number appears. Leave that screen open.
  3. Type the number here.

Paired ✓

4. Rest mode settings (for Wake)

To wake the PS5 from this app, turn on both of these on the PS5 under Settings → System → Power Saving → Features Available in Rest Mode:

  • Stay Connected to the Internet
  • Enable Turning On PS5 from Network

Then test it: rest mode first, wait for the orange light, then wake.
